# Chai Sales EDA

A beginner-friendly EDA practice project built around a fictional chai shop sales dataset.

## Dataset
`chai_sales.csv` contains 650+ sales records with:
- dates, days and order hours
- 8 cities
- 8 chai varieties
- sizes, quantities and prices
- discounts and total order amount
- payment methods
- customer types
- dine-in, takeaway and delivery orders
- weather and temperature
- ratings and preparation time
- sugar and milk preferences
- repeat-customer information

The raw dataset intentionally contains a few missing values, duplicate rows,
inconsistent text values and outliers so data cleaning is meaningful.

## Notebooks
1. EDA Basics
2. Data Cleaning
3. Univariate Analysis
4. Bivariate Analysis
5. Multivariate Analysis
6. Feature Engineering
7. Preprocessing
8. Complete EDA Project

## Requirements

```bash
pip install pandas matplotlib jupyter
```

Open the folder in VS Code/Jupyter and run the notebooks in order.
